About the Artbook

This digital artbook was created as part of a web development project to demonstrate HTML, CSS, responsive design, and project planning skills. The website presents a curated collection of artwork, fashion inspiration, and visual design concepts from various creative artists I admire.

The purpose of this project is to explore how digital platforms organize and present visual storytelling through art, fashion, design, and approaches to visual communication.

The website design uses an editorial inspired layout influenced by modern fashion publications and digital artist work. Typography, spacing, and visual hierarchy were selected to create an engaging and professional browsing experience.

All featured artwork belongs to the original creators and is displayed for educational purposes with proper attribution provided.
