About the Artbook

This digital artbook was created as part of a web development project to demonstrate HTML, CSS, responsive design, and project planning skills. The website presents a curated collection of artwork, fashion inspiration, and visual design concepts from various creative artists.

The purpose of this project is to explore how digital platforms can organize and present visual storytelling through art, fashion, and design. Each featured piece represents different creative styles, techniques, and approaches to visual communication.

The website design uses an editorial-inspired layout influenced by modern fashion publications and digital galleries. Typography, spacing, and visual hierarchy were carefully selected to create an engaging and professional browsing experience.

All featured artwork belongs to the original creators and is displayed for educational purposes with proper attribution provided.
