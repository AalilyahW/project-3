# Project-3-# Creative Visual Design Showcase

## Project Overview
This website was developed as a final project for CMPA 3301 to demonstrate front-end web development, responsive layout design, custom typography integration, and professional project management principles. 

Rather than serving as a personal freelance portfolio, this platform functions as a highly focused, curated educational showcase. It brings together a professional collection of digital art, fashion inspiration, and editorial design concepts from independent creators to explore visual storytelling across media formats.
