# Project Retrospective & Final Reflection

### 1. What Went Well?
*   **Rigorous Scope Control:** Transitioning the project to a curated educational showcase allowed me to dig deeply into modern layout mechanics, external asset integration, and custom typography configurations without missing deadline milestones.
*   **Deployment Pipeline Efficiency:** Setting up a predictable file architecture and verifying local adjustments before pushing directly to the main branch kept the pipeline simple and stress-free.

### 2. What Could Be Improved?
*   **Asset Management Lead Time:** Sourcing high-resolution editorial assets and tracking down their correct creator attribution names took longer than expected during the active coding window. Gathering a media log earlier would have optimized my initial layout momentum.

### 3. What Will I Do Differently Next Time?
*   **Proactive Asset Inventories:** In future web design sprints, I will build a dedicated asset worksheet (containing confirmed image paths, source titles, and artist credits) during the week 01 scoping phase before writing functional code.
