### Risk Management Analysis (TAME Framework)
*   **Risk 1: Scope Creep (Adding excessive pages or storefront features)**
    *   *Mitigation Strategy:* Restricted the project boundaries strictly to a two-page layout architecture (index.html and about.html) to deliver professional design quality over sheer file volume.
*   **Risk 2: Intellectual Property & Content Attribution Errors**
    *   *Mitigation Strategy:* Enforced a zero-tolerance layout metric using semantic HTML <figure> and <figcaption> elements to guarantee 100% of curated items feature clear, visible creator attributions.
